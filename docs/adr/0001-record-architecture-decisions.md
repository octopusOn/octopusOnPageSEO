# ADR 0001 — Record architecture decisions

- Status: accepted
- Date: 2026-10-12

## Context
SEONexus is an open-source, multi-product codebase. Contributors need to understand *why* structural choices were made, not just *what* the code does.

## Decision
Significant decisions are recorded as numbered Markdown files in `docs/adr/` using the format: Status, Date, Context, Decision, Consequences. Superseded ADRs are kept and marked `superseded by NNNN`.

## Consequences
Architectural changes require a PR that adds or updates an ADR.
