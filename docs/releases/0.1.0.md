First public release of the octopusSEO Log Analyser: a desktop app and the `snx-log` command line for SEO log file analysis.

## Highlights

- **Verified bots**: 110+ crawlers recognised and checked against official IP lists and reverse DNS; fake Googlebots are flagged.
- **AI visibility**: AI training, AI search and AI assistant crawlers in separate categories, plus visits referred by ChatGPT, Perplexity, Gemini, Copilot and Claude.
- **robots.txt compliance**: requests to disallowed URLs per bot, evaluated like Google does.
- **Crawl budget**: crawl frequency, last crawl, response codes, redirects, slow and large URLs per URL and directory.
- **Orphan and uncrawled pages**: compare crawler exports and XML sitemaps with what bots actually requested.
- **39 ready-made reports** and a query language; Excel, CSV and JSON exports.
- **Countries and networks** of client IPs, looked up locally.
- **Formats**: Nginx, Apache, IIS, CloudFront, AWS load balancers, HAProxy, Traefik, Caddy, Cloudflare, Google Cloud, JSON and CSV — detected automatically.

## Installation notes

- **macOS**: the app is not notarized yet. If macOS says it cannot verify the developer, open **System Settings → Privacy & Security** and choose **Open Anyway**.
- **Windows**: SmartScreen may warn about an unknown publisher; choose **More info → Run anyway**.
