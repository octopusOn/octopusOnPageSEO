The OctopusOn Log Analyser joins the OctopusOn SEO suite: same free, open-source log file analyser, now with a new name, its own GitHub project and the `octopuson-log` command line.

## Highlights

- **New name and home**: octopusSEO Log Analyser is now OctopusOn Log Analyser, released from [octopusOn/log-analyser](https://github.com/octopusOn/log-analyser). Existing data, saved queries and `.snxsite` archives keep working.
- **New command name**: the CLI installs as `octopuson-log` (it was `snx-log`).
- **OctopusOn account card**: optionally sign in to see your OctopusOn credit balance next to the other programs. Log analysis itself needs no account and stays free.
- **Refreshed design** shared with the other OctopusOn SEO programs, with its own colour and icon.

## Installation notes

- **macOS**: the app is not notarized yet. If macOS says it cannot verify the developer, open **System Settings → Privacy & Security** and choose **Open Anyway**.
- **Windows**: SmartScreen may warn about an unknown publisher; choose **More info → Run anyway**.
