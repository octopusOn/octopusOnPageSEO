# Security Policy

## Reporting a vulnerability

Please **do not** open public issues for security problems. Report them privately via
GitHub Security Advisories ("Report a vulnerability" on the repository's Security tab).

We aim to acknowledge reports within 3 business days and to publish a fix or mitigation
within 30 days for confirmed issues.

## Scope

- Log parsing of untrusted input (crashes, excessive memory/CPU use)
- Query language → SQL compilation (injection)
- Desktop app IPC and filesystem access
- Update channel integrity
